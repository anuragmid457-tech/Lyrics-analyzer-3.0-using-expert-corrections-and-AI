# Analyser stack.
#
# The <0.4 caps matter. langchain-google-genai 4.x was rewritten against
# Google's consolidated SDK and requires langchain-core >= 1.3, which cannot
# coexist with the 0.3 line your analyser files are written for. Pinning the
# genai package below 3.0 states that directly instead of leaving pip to
# discover it by backtracking.
langchain>=0.3,<0.4
langchain-core>=0.3,<0.4
langchain-community>=0.3,<0.4
langchain-google-genai>=2.0,<3.0

# PyPDFLoader's backend, used by detect_emotion().
pypdf>=4.2

# Nothing else is needed. Cosine similarity in learning.py is plain Python and
